# ExpenseAnalyzer

A modern, interactive expense analysis tool built with React, TypeScript, and Vite. Upload your expense CSV files and get instant visualizations and insights into your spending habits.

## 🚀 Features

- **Multi-File Support**: Upload and analyze multiple CSV files simultaneously.
- **Interactive Dashboards**: Filter data by clicking on chart categories or specific dates.
- **Timeframe Views**: Toggle between Weekly, Monthly, and Yearly views with ease.
- **Bidirectional Support**: Full localization for both English (LTR) and Hebrew (RTL).
- **Detailed Drill-down**: Intersectional filtering between charts and a unified transaction table.
- **Mobile Friendly**: Fully responsive design for use on any device.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Charts**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Date Handling**: [date-fns](https://date-fns.org/)
- **Bundler**: [Vite](https://vitejs.dev/)

## 🏃 Getting Started

1.  **Clone the repository**
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run development server**:
    ```bash
    npm run dev
    ```
4.  **Build for production**:
    ```bash
    npm run build
    ```
